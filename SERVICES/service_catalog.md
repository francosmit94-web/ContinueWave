# Service Catalog
# Status: active
# Purpose: simple service reference for AtlasFlow

## Positioning
AtlasFlow sells outcomes, not vague AI or generic marketing.

The core outcomes are:
- cleaner pipeline
- better lead handling
- stronger positioning
- improved booking or enquiry conversion
- more trust in difficult markets

## Core Services

### Regulated Growth Support
For cannabis, CBD, telemedicine, and compliance-sensitive businesses.

What it includes:
- offer positioning
- landing page strategy
- trust and authority building
- conversion-path design
- selective lead generation support

### Practitioner Growth Support
For doctors, dentists, chiropractors, GPs, physicians, and local practices.

What it includes:
- patient pipeline review
- local acquisition improvements
- website and booking flow cleanup
- faster response and better lead handling

### Lead Response Engine
For practices and service businesses leaking leads through slow or weak follow-up.

What it includes:
- response flow design
- qualification logic
- handoff path
- basic reporting structure

### Inbox and Admin Automation
For businesses carrying too much repetitive admin and inbox drag.

What it includes:
- triage logic
- response templates
- follow-up structure
- workflow cleanup

### Outbound Engine
For B2B operators who need a cleaner path to qualified conversations.

What it includes:
- list logic
- message angles
- outreach structure
- reply handling
