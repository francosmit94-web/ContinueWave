# AtlasFlow v1 Finish Line

## Purpose
- Define the minimum condition for calling AtlasFlow v1 finished.

## v1 Is Done When
1. All three live hosts are aligned
- Vercel
- Netlify
- GitHub Pages

2. The current runtime is deployed everywhere
- contact-intent tracking live
- email fallback behavior explicit
- no misleading success semantics

3. GA4 is configured against real runtime behavior
- `conversion_email_intent` marked as a conversion
- `conversion_phone_intent` marked if phone links are used
- `conversion_whatsapp_intent` marked if WhatsApp links are used

4. The offer is operational
- one niche selected
- first 20 outreach messages prepared or sent

## Not Required For v1
- same-origin backend
- full multi-agent hierarchy
- polished operator product packaging
- final model/provider elegance

## Current Remaining Manual Steps
- mark conversion events in GA4
- choose one niche
- start first outreach wave

## Rule
- Do not reopen system-design work before these are handled.
