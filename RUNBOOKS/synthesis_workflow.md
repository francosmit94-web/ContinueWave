Synthesis Workflow

Purpose
- Define how ContinueWave should review prior material without importing mess.

Default Rule
- Review one source at a time.

Workflow
1. Identify one source file or source folder.
2. State why it is being reviewed.
3. Extract only what improves:
   - clarity
   - execution
   - decision quality
   - reusable assets
   - operating structure
4. Reject:
   - duplication
   - stale plans
   - vague philosophy
   - emotional clutter
   - tool-shaped residue
5. Rewrite useful ideas into ContinueWave language.
6. Store the result in a clean current file.

Review Questions
- Is this still relevant now?
- Does it improve the system or a live payload?
- Can it be reused cleanly?
- Does it increase clarity or just add noise?

Outputs
- evolution notes
- rewritten clean briefs
- selected imports only when justified

Rule
- Never import a source file wholesale unless it is already clean enough to belong.
