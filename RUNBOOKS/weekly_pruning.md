Weekly Pruning

Purpose
- Keep ContinueWave clean as it grows.

Review
- files created this week
- placeholders that never became useful
- duplicate docs
- stale queue items
- payload docs that no longer matter

Prune
- archive low-value material
- delete obvious junk
- merge duplicate documents
- rewrite unclear files instead of adding more files on top

Check
- does the system layer still feel calm?
- does the payload layer still feel focused?
- is the next move obvious?

Rule
- weekly pruning should reduce cognitive load, not create more work.
